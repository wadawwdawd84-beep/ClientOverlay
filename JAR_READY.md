1. Download [Fabric Installer](https://fabricmc.net/use/installer/)
2. Select Minecraft 1.21.1
3. Click Install

### Step 2: Copy JAR
Copy `clientoverlay-1.0.0.jar` to your mods folder:
- **Windows:** `%APPDATA%\.minecraft\mods\`
- **Linux:** `~/.minecraft/mods/`
- **Mac:** `~/Library/Application Support/minecraft/mods/`

### Step 3: Launch & Play
1. Start Minecraft with Fabric profile
2. Load into a world
3. Look for `[ClientOverlay] Initialized successfully!` in console

### 2. Entity Info Overlay
- Player names, distance, health bars
- Teammate detection (Scoreboard)
- Filter invisible players
- Skips local player in first-person

### 3. Detached Camera
- Toggle with F6
- Free movement with WASD + Space/Shift
- 3x speed with Ctrl
- Player stays in place while camera moves

## ⚙️ Configuration

**File:** `~/.minecraft/config/clientoverlay.json`

**Auto-created** on first launch with defaults. Edit to customize:

```json
{
  "spawnerWireframeEnabled": true,
  "spawnerWireframeRadius": 64,
  "spawnerShowEntityType": true,
  "entityInfoEnabled": true,
  "entityInfoShowHealth": true,
  "entityInfoSkipTeammates": true,
  "entityInfoSkipInvisible": true,
  "detachedCameraEnabled": false,
  "detachedCameraBaseSpeed": 0.1,
  "detachedCameraSpeedMultiplier": 3.0
}
```

Or use the in-game GUI (Shift+Z) to toggle features.
